# CANOPY delivery roadmap

The purpose is to build an evidence-backed reference design and interactive research model **before** buying land or designing permanent foundations.

| Stage | Indicative horizon | Proof to exit |
| --- | --- | --- |
| 0. Baseline | 0–24 months | Site rights, GIS ecology, climate, hydrology, feasibility, affordability |
| 1. Pilot quarter | Years 2–6; ~1,500–3,000 people | 2–3 mixed-use blocks, wetland demonstrator, transit stop, utility pilot; 12–24 months audited operations |
| 2. Three districts | Years 6–14 | Functional school, clinic, food, fabrication, transit and utility redundancy |
| 3. Six districts | Years 14–25+ | Ecological indicators, affordability, emergency resilience and independent audit |
| 4. Evolution | Continuous | Renovation and managed retreat/extension as warranted, decade-scale revalidation |

## Software deliverables

- [x] Define the canonical acronym and open-source repository
- [x] Commit reference land allocation, district identities and assumptions
- [x] Publish an interactive concept explorer with source/state disclaimers
- [ ] Add independent geospatial layers for a selected real site
- [x] Add a versioned export contract for explicitly synthetic scenario results
- [ ] Add validated and typed open-ledger records for observed resources, provenance and uncertainty
- [x] Add editable synthetic water/energy scenarios and normalized hourly demand/generation profiles
- [ ] Replace synthetic profiles with verifiable, site-specific hourly weather and consumption datasets
- [ ] Add habitat connectivity, flood and wildfire constraint overlays
- [ ] Add accessible printable planning sheets and reproducible exports
- [ ] Conduct privacy threat modeling, engineering reviews and community workshops

## Physical pilot criteria

No construction concept progresses without site-specific ecology, verified water supply, tested flood/fire/seismic conditions, safety and accessibility compliance, affordability commitments, human-controlled fail-safe infrastructure, and transparent lifecycle evaluation.
